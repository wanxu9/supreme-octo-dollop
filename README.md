# 马克思主义在中国的传播简史 · 网站说明

马原课程小组作业。一个单页站点：左边是中国地图，右边是当前事件的详情，
下方是可拖动的时间轴，串起 1899—1921 年的 22 个关键节点。

## 怎么打开

直接双击 `index.html` 即可，不需要服务器、不需要联网。
（地图数据 `js/china.js` 已经打包在本地，没有 CDN 依赖。）

想在手机上看，把整个文件夹传到任意静态托管，或在本机起一个服务：

```bash
python -m http.server 8000
# 然后手机访问 http://<电脑局域网 IP>:8000
```

## 相比原版的改动

1. **时间轴从 1915—1921 扩到 1899—1921**，并按史料补到 22 个节点：
   1899《万国公报》、1902 梁启超、1906 朱执信、1917 十月革命、1918 李大钊、
   1919 北京四条（每周评论、五四、问题与主义、我的马克思主义观）、
   1919 长沙三条（湘江评论、民众的大联合、赵五贞事件）、
   1920 上海五条、1920 北京两条、1920 武汉、1921 广州、1921 中共一大。
2. **事件内容全部换成带出处的史料**，每条都有「时间 / 地点 / 人物 / 经过 / 意义 / 出处」，
   引自小组收集的各地素材与《中国共产党大事记》等公开资料。
3. **地图重做**：不再用 ECharts GL（要 WebGL、要 CDN、手机上卡），
   改为用本地 GeoJSON 直接绘制中国地图，事件城市按时间顺序连成传播路线，
   当前节点所在省份高亮，域外的彼得格勒单独标注。
4. **交互**：可拖动时间轴、← → 键切换、空格自动播放、点击地图城市跳转、
   地址栏 `#e1902` 这样的锚点可以直接定位到某个节点。
5. **新增**：三个阶段（译介 / 勃发 / 落地）的概括、14 位人物卡片、12 条参考资料、
   移动端适配、`prefers-reduced-motion` 支持。

## 目录

```

js/app.js           时间轴、事件卡、列表、人物、键盘交互
js/china.js         中国省级 GeoJSON（本地打包）
```

## 怎么改内容

只需要动 `js/data.js`：

- **加一个事件**：往 `EVENTS` 里按顺序插一个对象，字段如下；
  时间轴、地图、清单、进度会自动跟着变。

```js
{
  id: 'e1922',            // 唯一 id，也用作地址栏锚点 #e1922
  stage: 2,               // 0 萌芽 / 1 勃发 / 2 落地
  city: 'sh',             // CITIES 里的城市 id
  date: '1922 年 7 月',
  title: '一句话标题',
  place: '地点 · 刊物',
  people: ['人名'],
  desc: '经过（2—4 句）',
  meaning: '历史意义（1—2 句）',
  source: { label: '出处名称', url: 'https://…' }
}
```

- **换城市**：改 `CITIES` 里的经纬度；新城市要在 `EVENTS` 里用它的 id。
- **改人物 / 参考链接**：`PEOPLE`、`SOURCES`。
- **改阶段划分**：`STAGES`（名称、起止年、颜色）。

改完刷新页面即可，不需要构建。

## 发布到 GitHub Pages

仓库是 `https://github.com/wanxu9/supreme-octo-dollop`（Pages 已经在跑）。
把本文件夹里的 `index.html`、`css/`、`js/` 覆盖到仓库根目录，然后：

```bash
git add -A
git commit -m "重做时间轴与地图，补齐 1899—1921 年史料"
git push
```

原来的 `文献资料/`、`图片资料/` 可以留在仓库里，不影响页面运行。
